# 02 · 快速开始

## 2.1 环境要求

- Python 3.10+（本仓库在 3.11 下开发验证）
- 阿里云百炼（DashScope）API Key
- Windows / macOS / Linux 均可

## 2.2 安装依赖

```bash
cd AFAC2026
python -m venv .venv

# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt
```

## 2.3 配置密钥

```bash
cp .env.example .env
```

编辑 `.env`，填入 `DASHSCOPE_API_KEY`。Key 在[阿里云百炼控制台](https://bailian.console.aliyun.com/)创建。

> 安全提醒：`.env` 已被 `.gitignore` 排除，**永远不要**把它提交到 Git。

## 2.4 环境自检

```bash
python scripts/check_env.py
```

脚本会检查四件事：

1. 依赖包是否齐全
2. `.env` 与 API Key 是否就绪
3. 题目目录、提交模板、文档注册表、分块文件是否存在
4. （可选 `--api`）真实调用一次 DashScope 确认连通

## 2.5 准备数据与索引

本仓库默认不携带原始 PDF 与生成的索引（体积大）。首次运行需要两步：

```bash
# 1) 把官方数据放到 data/raw/raw/ 下（结构见 docs/03）
# 2) 分块 + 构建 BM25 索引
python scripts/build_index.py build
```

如果克隆后自带 `data/chunks/`，可以跳过分块直接建索引。

## 2.6 跑通全流程（离线演示版）

没有 API Key 时，可以先验证检索与提交链路：

```bash
# 检索测试
python scripts/build_index.py search "身故保险金如何计算"

# 索引统计
python scripts/build_index.py info

# 用官方 B 榜题目 + 样例答案，生成提交 CSV（格式验证）
python scripts/build_submission.py --answers output/answers.json
```

## 2.7 运行 Agent（真实推理，需要 API Key）

```bash
# B 榜全部 100 题，5 线程
python scripts/run_agent.py --split B --workers 5

# 只跑保险领域前 3 题（联调省钱）
python scripts/run_agent.py --split B --domain insurance --limit 3
```

运行产物：

| 文件 | 内容 |
|------|------|
| `output/answers.json` | 全部答案 + 每题的 token 统计 |
| `output/evidence/<qid>.json` | 每题检索到的证据片段 |
| `output/logs/<qid>.log` | 每题摘要日志 |
| `output/run_log.txt` | 进度日志 |

然后生成提交文件：

```bash
python scripts/build_submission.py --answers output/answers.json --out output/submission.csv
```

## 2.8 常见误区

- 目录不对：所有脚本内部会 `chdir` 到项目根目录，但建议始终在项目根目录执行命令。
- 忘记激活虚拟环境：`python` 可能指向系统解释器，用 `which python`（或 `where python`）确认。
- 漏装依赖：`check_env.py` 第一项会直接告诉你缺什么。
